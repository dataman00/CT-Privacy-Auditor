# Extension Name 🛡️

A lightweight browser extension that audits websites in real-time to reveal which data brokers, trackers, and monitoring scripts are loading in the background. 

Optimized with a focus on **Connecticut data privacy standards**, though useful for users worldwide.

## ✨ Features
* **Real-time Detection:** Instantly flags known data broker scripts and tracking pixels.
* **CT Privacy Alignment:** Highlights trackers relevant to the Connecticut Data Privacy Act (CTDPA).
* **100% Private:** This extension **does not collect, store, or transmit** any user data. Everything runs locally in your browser.

## 🛠️ How to Install (Developer Mode)
1. Clone this repository or download the ZIP file.
2. Open your browser and navigate to the extensions page (e.g., `chrome://extensions` or `about:debugging`).
3. Enable **Developer mode** (usually a toggle in the top right).
4. Click **Load unpacked** and select this project folder.
